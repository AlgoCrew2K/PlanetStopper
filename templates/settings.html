Master controls
The mode and the start time that govern real-money execution, so treat both with care.
Live execution —
When Live, the bot sends Composer a real sell-to-cash order the moment a stop is hit. Dry run tracks identical math but never sends an order — used to validate parameters before flipping the switch.
Real-money mode. Every trigger will send a liquidation to Composer. Discord receives an audit alert on every panic-stop call regardless of live state.
Live trading is armed in the server's .env file, not from the dashboard. This switch shows the current mode and cannot change it.
Execution start time (ET)
ET
The minute the scheduler begins monitoring stops. Market opens 09:30; an earlier time lets the engine prepare its state before the open.
Algorithm parameters
Global defaults for every symphony; a per-symphony override in the next section takes precedence.
Credentials
The keys, account ids and webhook address the bot uses for Composer, Alpaca, Discord and Anthropic, shown masked.
Heads up. The dashboard cannot save these fields, and a save that includes one is refused with nothing written. To change a credential, edit the .env file on the host; some keys take effect only after the daemon restarts.

Maintenance
Data operations that cannot be undone, so use each with care.
Note. This operation deletes fabricated synthetic files. Real captured data is never touched. Do not run while market hours are active.
Sync & Flush synthetic post-mortem data
Deletes fabricated synthetic post-mortem snapshot files (post_mortem_YYYY-MM-DD.json), keeps the real captured ones, clears the analytics history cache, and re-syncs account totals from Composer. Use this to purge seeded or synthetic data so the dashboard reflects only real history.

This will reset tracked state for all symphonies, delete synthetic post-mortem files, clear the analytics cache, and re-sync account totals from Composer. Real captured data is preserved.

    Synthetic post-mortem: a daily exit record that was generated or seeded rather than captured live. Re-syncs account totals: reads the account totals from Composer again.
