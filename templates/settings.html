Master controls
The two switches that govern real-money execution. Treat both with respect.
Live execution DRY RUN
When LIVE, the bot fires real POST /go-to-cash requests to Composer the moment a stop is hit. DRY RUN tracks identical math but never sends an order — used to validate parameters before flipping the switch.
⚠ Real-money mode. Every trigger will send a liquidation to Composer. Discord receives an audit alert on every panic-stop call regardless of live state.
Execution start time (ET)
ET
The minute the scheduler begins monitoring stops. Market opens 09:30; earlier values stage state pre-open.
Algorithm parameters

Credentials
Keys + account UUIDs + webhook URLs. Values are write-only — the server returns masked placeholders so secrets never round-trip through the browser.
