## Execution Model
One Toxic Pair per cycle, each in its own worktree under `.claude/worktrees/` on its own branch `ux-data-truth/c<n>`, built test-first (`/tdd` then `/tdd-implement`, closed with `/tdd-finalize`). Every kickoff copies `.env` into the worktree and requires `git rev-parse --show-toplevel` and `git rev-parse --abbrev-ref HEAD` to match the brief before any edit, because teammates inherit a non-worktree cwd and a bare `git` reaches the primary checkout (project memory). Test runs are scoped to the files the cycle names, with `-n0` or at most 4 workers, never `-n auto`, output to a file, in the background.

Pair specialisations (the implementer is dispatched as the project specialist for the surface; the test-writer as `quant-test-writer` where it pins a formula):
- C1: implementer `flask-dashboard-specialist`; the `database.py` accessor and the `autotuner.py` extraction sit in the same cycle because the route reads them; test-writer `quant-test-writer` (the objective rule is optimizer semantics).

- C6: implementer `flask-dashboard-specialist`; test-writer `test-writer`; owns SC-7 (marker registration, the `addopts` change, `tests/ui/_browser_server.py` and the meta test). Reviewers per head, in parallel at cycle-complete: `qa`, `code-reviewer`, `ux-expert` with `behavioral-evidence-capturer` (every cycle renders UI: C1 Overview and Frontrunner, C2 Correlations and Strategy Builder, C3 History, C4 and C5 Performance, C6 Settings, C7 modal on `/`, C8 all six name sites), screenshots by the suite's screenshot gate protocol (`00-suite.md` Per-Cycle Test Plan): launcher Mode A (SC-8), Firefox, 1440x900 and 375x812, light and dark, against the audit captures in `.claude/review/37c8e983b64c/ux-audit/`, each capture carrying SC-8's record.
