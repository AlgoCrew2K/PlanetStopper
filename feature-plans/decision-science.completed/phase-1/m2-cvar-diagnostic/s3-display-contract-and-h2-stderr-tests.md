| Why | S-3 is binding — M2 without the four-part display is **mildly harmful** (per the synthesis): an operator anchors on a reassuring number that is systematically too mild. H-2 is the single highest-stakes correctness fix in the v3 evaluation: a stderr computed on 5000 resampled draws understates true estimation error by ~27× and converts S-3's honesty mechanism into a false-precision generator. The §B residue's `cvar_5pct_long` column must coexist with the REJECT of a `cvar_divergence` value — the test pins both at once. |
| Deliverables | (1) `tests/math_engine/test_cvar_5pct_estimator_pin.py` — fixture: a captured 150-day kNN-style pool whose 5% tail contains exactly 7 distinct sub-5% returns hand-derived in Python; assert `cvar_5pct` equals the Rockafellar-Uryasev general-distribution estimator value to within 1e-12. Independent reference value computed by `numpy.quantile` + tail mean with explicit atom handling — NOT by calling the production estimator. (2) `tests/math_engine/test_cvar_5pct_stderr_uses_distinct_tail_count.py` — fixture configured with `simulation_paths=5000` AND `distinct_tail_count=7`; assert the returned `cvar_5pct_stderr` is within tolerance of the small-sample (n=7) standard error and **explicitly NOT** within tolerance of the n=5000 value (the test fails RED if the implementation divides by `√5000`). (3) `tests/app/test_m2_display_four_part_s3_contract.py` — renders the M2 display fragment; asserts presence of all four elements: a numerical stderr value, a `cvar_n_tail` count, the verbatim string "diagnostic, not a signal — do not trade on this", and a verbatim bias-warning string ("this CVaR estimate is a known-low-biased LOWER BOUND on tail severity, not a point estimate" or substring with the load-bearing tokens `known-low-biased`, `LOWER BOUND`, `not a point estimate`). (4) `tests/math_engine/test_cvar_5pct_insufficient_returns_none_sentinel.py` — fixture: a pool with `< MC_MIN_HISTORY_DAYS` eligible tail observations; assert `cvar_5pct is None`; assert the paired `breach` (or `cvar_breach` flag if exposed) is `False`. (5) `tests/app/test_m2_display_no_divergence_surfaced.py` — even when `cvar_5pct_long` is populated, no `cvar_divergence` / `regime_recency_weight` / signed-delta value appears on any rendered display surface or persisted display payload; both window values are rendered independently each under their own four-part S-3. |
