# Plan — Phase-2 Test Design: Joint VaR-ES Coverage Backtest (Acerbi-Székely / Fissler-Ziegel)

| Field | Value |
|---|---|
| Feature | Phase-2 Gate-2 calibration test design — a joint VaR-ES coverage backtest using Acerbi-Székely / Fissler-Ziegel machinery, applied to the Phase-2 forward-path simulator's CVaR estimates against realized tails over the shadow window. **Power-aware**: the design must include a power calculation against AlphaBot's data scale; if the calculation says the test is structurally underpowered, this gate degrades to "diagnostic-grade-permanent" per precondition (d). |
| Phase | 2 (test design ships only AFTER the Phase-2 precondition gate passes) |
| Owner agent-type | `quant-test-writer` (test design) + `quant-risk-researcher` (statistical machinery) + `quant-code-reviewer` (gate) |
| Source-of-truth refs | `docs/handoff/decision-science-council-synthesis.md` §2.3 (decisive finding — ~1,000-tail-obs wall), §5.5 (Phase-2 Gate 2 — never a raw P&L backtest); `docs/handoff/council-attack-rubric.md` K-2 ★ (joint VaR-ES not standalone-elicitable; Fissler-Ziegel 2016); `decision-science-eut-cvar-research-2026-05-22.md` §2.4 (the machinery); `decision-science-v3-and-divergence-evaluation.md` §A.0 (validation wall confirmed against `math_engine.py:705-833`) |
| Why | ES is not standalone-elicitable (Fissler-Ziegel 2016); the only honest validator is a joint VaR-ES coverage test (Acerbi-Székely class). At AlphaBot's data scale (~37 tail days per 3 years) this test is structurally underpowered — the test design must surface that fact **before** the test runs, not after. A passing-by-default underpowered test would manufacture false validation. |
| Deliverables | (1) `docs/handoff/phase-2-gate-2-joint-var-es-test-design.md` — the test design with: (a) the joint VaR-ES coverage statistic chosen (Acerbi-Székely Z1 or Z2; or Fissler-Ziegel scoring function); (b) the pre-registered significance level, sample size, and run length; (c) the power calculation against AlphaBot's empirical tail rate (~6 per 125-day fold) — explicit conclusion: "test power = X% at effect size Y"; (d) the no-go branch if power < 80%: degrade to diagnostic-grade-permanent under precondition (d), never call this a "calibration" test. (2) `tests/integration/test_phase_2_gate_2_design_is_pre_registered.py` — opens the design document, asserts the four elements (a/b/c/d) are present and pre-registered before the test runs (rubric K-2 — pre-registered, not retroactive). (3) The actual test harness `tests/integration/test_phase_2_gate_2_joint_var_es_coverage.py` — Phase-2-conditional, marked `@pytest.mark.skip(reason="Phase-2-only; activate after precondition gate passes")` until the gate clears. (4) The "what we do on failure" branch: if the gate runs and fails, the gate's data is **burned** (rubric K-3) — no re-tune from the failed evidence; a fresh OOS window is required. |
| Dependencies | Phase-2 precondition gate (`phase-2/binding-preconditions/plan.md`); Phase-2 simulator plan (`phase-2/simulate-forward-paths/`); Phase-2 schema migrations 016-018 (persistence-architect-owned). |
| Golden-fixture tests required | Test 3 is the actual coverage test; tests 1, 2 are pre-registration enforcement. The Acerbi-Székely / Fissler-Ziegel test statistics have published reference implementations — fixtures must reference them, never re-implement and self-validate (rubric D-2 non-circular). |
| Definition of Done | (a) Test design document is committed and pre-registered. (b) Power calculation is **stated explicitly** with the conclusion documented; if the calculation shows underpowered, the degradation to "diagnostic-grade-permanent" is the committed branch. (c) Test 3 is skip-marked until the precondition gate clears; activation is a deliberate uncommit-skip PR. (d) Reviewer cites K-2 if any future PR replaces this test design with a raw-P&L backtest. |
| Risk callouts | **R1 — Test design omits the power calculation**: rubric K-2 fail — the council brief says "structurally underpowered" must be acknowledged before the test runs. **R2 — The degradation branch is forgotten**: the design document must commit to the degradation path; an underpowered test should not run AT ALL — it should be replaced by the diagnostic-grade-permanent label. **R3 — A "compromise" two-tier test (run it and report power)**: ALSO acceptable if the report is committed and the power conclusion is acknowledged in any reviewer or operator decision; but a passing-because-underpowered test cited as validation is rubric L-3 (novel composition treated as established) and is REJECTED. |
| Out of scope | The simulator's correctness (separate plan); the trigger's hysteresis logic (separate plan); P&L-based gates (K-2 forbids); the Phase-1 Gate 2 diagnostic-quality form (separate Phase-1 plan); calibration of the Phase-2 generator family (Politis-White block-length selection or GARCH-FHS — those are spec-frozen by stylized-fact tests on the return series itself, NN1, not by this Gate-2). |
