# Plan (critic overlay) — Phase-2 Test Design: tier1_seed Deterministic Seeding

> Companion test plan to the risk-architect-owned `tier1-seed-determinism/plan.md`
> in this folder. Critic-domain overlay: enforces rubric M-2 (persisted derived
> artifacts replay-deterministic from a recorded seed) and F-2 (bit-identical
> replay under a fixed seed) at the test boundary.

| Field | Value |
|---|---|
| Feature | Phase-2 replay-determinism anchor set: the Tier-1 pre-open batch's deterministic seed `tier1_seed = SHA-256(symphony_id ‖ trading_day ‖ spec_bundle_hash)` is persisted in `path_bank_manifest.tier1_seed`; a replay regenerates the path bank bit-identically from this seed and verifies by `path_bank_manifest.bank_sha256`. The Phase-2 anchor count is **exactly 5** (synthesis §3.7): (1) `tier1_seed`, (2) calibration params, (3) history fingerprint, (4) spec bundle, (5) hysteresis snapshot. |
| Phase | 2 |
| Owner agent-type | `quant-test-writer` + `quant-code-reviewer` (rubric M-2, F-2) + `risk-engine-specialist` |
| Source-of-truth refs | `docs/handoff/council-attack-rubric.md` M-2 ★, F-2 ★; `docs/handoff/decision-science-council-synthesis.md` §3.7 (anchor count = 5 in Phase 2; tier1_seed load-bearing for Gate 1), §5.3; `docs/handoff/council-converged-migration-plan.md` §3.2 row 017 (`path_bank_manifest.tier1_seed`), §6 H7; existing seed pattern `math_engine.py:695-702` (`derive_cycle_mc_seed`) — exact same shape: SHA-256 → 64-bit reduction → isolated `np.random.default_rng` |
| Why | An unpersisted or wall-clock-derived seed makes Gate 1 structurally unachievable (rubric M-2). The Phase-2 seed must be persisted at bank-build time and re-read at replay; the path bank file's SHA-256 must round-trip. Without these tests the Tier-2 read of a "different but plausible" bank would silently pass a replay diff and the bit-identity claim of Gate 1 would be hollow. |
| Deliverables | (1) `tests/math_engine/test_tier1_seed_derivation_pin.py` — assert `tier1_seed = int(SHA256(symphony_id ‖ trading_day ‖ spec_bundle_hash), 16) % 2**64`; the modulus and the concatenation order are PINNED — a regression flips the seed. (2) `tests/math_engine/test_tier1_seed_persisted_in_manifest.py` — Tier-1 batch builds a bank; manifest row contains the `tier1_seed` value matching the derivation. A bank built with a different (non-frozen) seed fails the test. (3) `tests/math_engine/test_path_bank_bit_identical_regeneration.py` — given a manifest row with `tier1_seed` and `bank_sha256`, regenerate the bank in a replay context; assert the regenerated file's SHA-256 equals `bank_sha256`. (4) `tests/math_engine/test_no_global_rng_used_in_simulator.py` — grep test: `simulate_forward_paths` and any helper called from it use `np.random.default_rng(seed)` exclusively; no `np.random.seed`, no `random.seed`, no `np.random.choice` on the module-level RNG. (5) `tests/integration/test_phase_2_anchor_count_is_five.py` — the Phase-2 anchor set is enumerated in a committed JSON; the test asserts the count is exactly 5 and each anchor's persistence column is named. (6) `tests/integration/test_tier2_read_of_stale_manifest_abstains.py` — Tier-2 reads `path_bank_manifest` and finds `superseded_at_utc` set; assert the simulator returns the `None` sentinel (fail-safe per F-4) and does not silently use the stale bank. |
| Dependencies | Migration `017_path_generator.sql` (persistence-architect); the simulator plan (`phase-2/simulate-forward-paths/`); the Phase-2 precondition gate (this only runs after the gate clears). |
| Golden-fixture tests required | All six tests are golden-fixture / structural tests. The reference SHA-256 in test 1 is computed by Python's `hashlib.sha256` directly, NOT by the production helper (non-circular). Tests 3 and 5 are byte-level fixtures (the bank SHA on disk). |
| Definition of Done | (a) Six tests pass GREEN once the simulator and the seed machinery exist; tests 1-3 fail RED before the seed lands. (b) The Phase-2 anchor count is exactly 5 — a 6th anchor added is a scope violation flagged loud. (c) The simulator uses zero global-RNG calls — test 4 grep-fails any regression. (d) Stale-bank reads abstain — test 6 holds. |
| Risk callouts | **R1 — `tier1_seed` derivation changes in a "small" PR** (different hash, different concatenation): tests 1, 3 fail loud. **R2 — `bank_sha256` is computed at write-time but never verified at read-time**: test 3 is the read-time verification. **R3 — A reviewer accepts "globally seeded numpy is fine because we set the seed at start"**: forbidden — rubric F-2's "isolated `np.random.default_rng`" is the only acceptable shape; test 4 catches. |
| Out of scope | The simulator's generator family (separate plan); the Tier-1 batch's actual latency budget (precondition (c) in the Phase-2 binding gate); calibration of the regime buckets (separate plan); the legacy-engine retention window (`council-converged-migration-plan.md` §6 H6). |
