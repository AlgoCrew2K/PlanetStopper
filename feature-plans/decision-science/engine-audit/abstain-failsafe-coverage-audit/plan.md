# Plan — Engine Audit: Abstain-Fail-Safe Coverage Audit (full stack)

| Field | Value |
|---|---|
| Feature | Read-only audit of the full call path from every sentinel-returning function (`run_monte_carlo` → `MC_INSUFFICIENT_HISTORY_SENTINEL = None`; future `simulate_forward_paths` → `CVaRAssessment(cvar_pct=None, breach=False, …)`; calibration failures; thin-bucket abstains) through every consumer to the protective-stop branch. **Reachable-call-path verification**, not file-scoped grep (per memory `feedback_audit_findings_need_call_path_verification` — the prior C-2 false-positive root cause). |
| Phase | Engine audit (post-Phase-1; re-runs at Phase-2 entry) |
| Owner agent-type | `quant-code-reviewer` (audit lead) + `risk-engine-specialist` |
| Source-of-truth refs | `docs/handoff/council-attack-rubric.md` F-4 (insufficient-data path returns out-of-band sentinel; protective stop still functions); `docs/handoff/decision-science-council-synthesis.md` §3.4 (Phase-1 sentinel discipline preserved), §5.3 (`CVaRAssessment.None`-implies-`breach=False` invariant); existing patterns at `math_engine.py:70-74`, `:739-744`; project memories `project_mc_sentinel_consumer_blast_radius`, `project_mc_eligible_pool_vs_raw_day_boundary`, `project_cluster5_d6_orphaned_red_triage`; the audit-findings memory `feedback_audit_findings_need_call_path_verification` |
| Why | The prior C-2 audit-finding false-positive came from a file-scoped grep claim that "X never happens in file F" without verifying the reachable call path from F. This audit's purpose is to do the call-path verification properly across every sentinel consumer — for both the existing `run_monte_carlo` sentinel and the future `CVaRAssessment` sentinel. F-4 is load-bearing: if any sentinel path silently disables the protective stop, the engine fails-permissive on tail risk. |
| Deliverables | (1) `docs/handoff/engine-audit/abstain-failsafe-call-paths.md` — the full call graph from each sentinel-returning function to the protective-stop branch, enumerated by `file:line` for every node. NOT a grep claim — every path is read end-to-end. (2) For each consumer enumerated in `project_mc_sentinel_consumer_blast_radius` (~7+ sites), the audit confirms the consumer treats `None` as "MC unavailable, do not veto," not as "MC said safe." (3) `tests/integration/test_protective_stop_fires_under_all_sentinel_paths.py` — fuzz across every documented sentinel-return mode (insufficient history, eligible-pool insufficient, kNN pool empty, future calibration failure, future thin bucket); assert the protective stop still fires on the ticks-below-stop condition alone. (4) `tests/integration/test_mc_history_buffer_handles_none_sentinel.py` — the `mc_history` buffer (chart history, port-level `mc_sanity_gate_would_block` snapshot, autotuner replay `mc_prob`) all handle `None` gracefully — NULL stored, never crash, never a fabricated zero (a fabricated zero is C-2 ★ kill — "biased permissive"). (5) `tests/integration/test_cvar_assessment_none_propagation.py` — Phase-2-conditional: every consumer of `CVaRAssessment` handles `cvar_pct is None` per the invariant `breach=False`; no consumer reads `cvar_pct` arithmetically without a `is not None` guard. |
| Dependencies | The MC-blast-radius plan (defines `CVaRAssessment` shape and the consumer enumeration); the priority-resolver ordering audit (the resolver respects the abstain). |
| Golden-fixture tests required | Tests 3, 4, 5 are integration / property tests. |
| Definition of Done | (a) Call-path document is committed; every `file:line` is read end-to-end (not grep). (b) Three tests pass GREEN. (c) Every existing consumer is annotated `# fail-safe: None means MC unavailable, protective stop continues to fire` at its `if mc_prob is None:` branch — a structural reading aid for future contributors. (d) **The audit is NOT a grep claim.** Every "X never happens" assertion is supported by a reachable-call-path enumeration. |
| Risk callouts | **R1 — A future consumer reads `cvar_pct` arithmetically without a None guard**: test 5 catches. **R2 — A "convenience" coerces `None` to 0.0**: rubric C-2 ★ kill — biased permissive. Tests catch. **R3 — The audit reverts to a file-scoped grep**: blocked by the memory `feedback_audit_findings_need_call_path_verification`; every claim must cite a call path. |
| Out of scope | The actual sentinel definitions (already in place); the CVaR estimator's correctness (separate plan); the Tier-1 batch's failure modes (Phase-2 precondition (c)). |
