## New Regressions (Cross-Cutting Grep Pass)

### D-COD-R01 — Hardcoded hex colors in `renderIntradayChart` and overlay toggle buttons
- **Files:** `static/index.js:302-303`, `templates/index.html:932-933`
- **Confidence:** HIGH
- **Risk:** STYLE (design-system contract violation)
- **Effort:** TRIVIAL

`static/index.js:302`:
```js
{ label: 'VWAP', data: vwapData, borderColor: '#8b5cf6', ...}
{ label: 'MC %', data: mcData, borderColor: '#f59e0b', ...}
```

`templates/index.html:932-933`:
```html
<button id="toggle-vwap" ... style="...color:#8b5cf6;...">VWAP</button>
<button id="toggle-mc"   ... style="...color:#f59e0b;...">MC</button>
```

Bare hex values `#8b5cf6` (violet/VWAP) and `#f59e0b` (amber/MC%) introduced during D-COD-04 fix. Neither is routed through `tokens.css`. The project rule is: all hex values are ONLY permitted as the RHS of a `--studio-*` variable declaration in `tokens.css`. These should reference existing token variables (e.g., `--studio-plum`, `--studio-warn`) or new `--studio-vwap-color` / `--studio-mc-color` tokens.

### D-COD-R02 — Hardcoded rgba grid color in `performance.js`
- **File:** `static/performance.js:148`
- **Confidence:** MEDIUM (single occurrence, Chart.js internal grid — less visible than surface colors)
- **Risk:** STYLE
- **Effort:** TRIVIAL

```js
grid: { color: 'rgba(0,0,0,0.1)' },
```

Grid color not routed through a CSS token. Will not update on theme switch. Correct pattern: `getComputedStyle(document.documentElement).getPropertyValue('--studio-rule').trim()` (same pattern used in `ai_advisor.js:332`).
